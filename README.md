# TB Manager | 티볼 통합 매니지먼트 시스템

중학교 티볼 수업의 실시간 경기 기록, 선수 분석, 기능평가와 TYPE1 포지션 시뮬레이션을 위한 **React + TypeScript + Vite PWA** v0.14입니다.

- 웹앱: https://yoursoul314.github.io/TBALL-manager/
- 저장소: https://github.com/yoursoul314/TBALL-manager
- 무손실 이전·백업 계약: [docs/MIGRATION.md](docs/MIGRATION.md)
- 개발 명세: [docs/SPEC.md](docs/SPEC.md)
- 확정·미확정 결정: [docs/DECISIONS.md](docs/DECISIONS.md)
- 검증 결과: [docs/VALIDATION.md](docs/VALIDATION.md)
- 학생·엔트리·공수 통합 기록 v3: [docs/ROSTER_DEFENSE_V3.md](docs/ROSTER_DEFENSE_V3.md)

감독 승인 배치안 → 새 경기 선발·수비 불러오기와 타순 수동 조정, 타격 측정·기록지·설정·분석 분리 화면을 제공합니다. 수비 횟수 설정, 9능력 설명, 키보드 대응을 유지하며 현재 schema14로 기존 원문을 보존해 이전합니다. [v0.12 변경 내용](docs/IPAD_DEFENSE_V12.md). [변경 내역·사용 순서](docs/APPROVED_ENTRY_STUDIO_V11.md).

## BETA 0.13 · 타구 질 및 펑고 워터폴

- 타격 6버튼(+5/+4/+2/+1/0/−1)과 9구역 필드맵. 원점수 평균을 B(10점)와 기능평가(100점)로 선형 환산합니다. 기존 1~10점 기록은 분리 보존합니다.
- 선수의 1·2지망을 입력하고, 날짜별 다중 학생 펑고 5구(간편) 또는 G/F/C/T_acc/T_pow 개별 점수(정밀)를 기록합니다. 미관찰은 null이며 정정·취소 원본을 유지합니다.
- 선발 시뮬레이션에서 기존 TYPE1 v2.0과 새 펑고 워터폴을 선택합니다. 포지션 공식·가산점·감점·내야 우선 배정 근거를 표시하고 감독 승인 후 경기 엔트리로 불러옵니다.
- schema12로 기존 원문·JSON 백업·사진을 보존합니다. [척도·배정·이전 명세](docs/BATTING_QUALITY_V13.md).

## 빠른 실행

Node.js 22.12 이상 (검증: 24.19), npm 사용.

```sh
git clone https://github.com/yoursoul314/TBALL-manager.git
cd TBALL-manager
npm ci
npm run dev
```

브라우저에서 터미널의 Local URL을 여세요. 기본 주소는 http://127.0.0.1:5173 입니다.

```sh
npm run typecheck
npm test
npm run build
npm run preview
# 전체 확인
npm run check
```

테스트 실행기는 Windows 샌드박스의 임시 디렉터리 rename 제한을 피하기 위해 프로젝트 내부의 무시된 캐시 디렉터리를 사용합니다. 일반 OS와 CI에서도 같은 명령으로 실행합니다.

## v0.10 아이패드 입력·시각화·수동 배치

수비 집중 모드는 9능력을 한 번에 표시하고 상황 선택과 저장·다음 학생을 같은 화면에 배치합니다. 타격 기록지는 **간편·상세 모드 모두 기본 접힘**으로 바꾸고, 펼쳤을 때도 회차/점수/결과/방향만 간단히 표시합니다. 회차를 선택하면 기존 상세 기록을 수정할 수 있습니다.

기능평가와 선수 비교에 경기장 모양 **9구역 히트맵**을 제공합니다. 두 선수 비교는 선택 목적에 따라 현재 자료에서 우선 검토할 선수와 근거를 제시하고, 우열이 갈리거나 표본이 부족하면 그 이유를 표시합니다. 선발 시뮬레이션에서 포지션 터치→학생 선택으로 수동 배치/맞교환/부분 초안 저장이 가능합니다. 이전 추천·승인안은 남기고 감독 승인은 별도로 진행합니다.

[schema10·검증·변경 파일·조작 단계](docs/TABLET_ASSESSMENT_V10.md)를 확인하세요.

## v0.9 수비 날짜 평가·선수 비교·기록지 접기

수비도 **날짜 생성 → 여러 학생 선택 → 상황 체크 → 저장·다음 학생** 순서로 평가합니다. 학생별 G·F·C·A·L·Q·M·J·B 점수를 당일/누적 표에서 비교하고, 관찰한 학생들의 누적 체크 점수를 기능평가 9항목에 함께 적용할 수 있습니다.

새 **선수 비교 & 선택** 메뉴는 타격 기능평가·실전 타격·수비 9능력·TYPE1 적합도와 표본 수를 나란히 표시합니다. 같은 출처·배점의 충분한 관찰만 상대적 장점/보완점으로 설명합니다. 선택은 검토 후보로 저장하며 새 경기에서 불러온 뒤 감독이 팀·엔트리를 편성합니다. 최종 종합 점수/순위는 만들지 않습니다.

타격 상세 모드의 기록지는 기본으로 접힙니다. **기록지 보기/숨기기**로 전환하며 작성 중인 값은 유지됩니다. [변경 파일·이전 방식·조작 단계·검증과 TODO](docs/DEFENSE_DAYS_COMPARE_V9.md)를 확인하세요.

## v0.8 학급 일괄 관리

경기 편성은 학년·반 필터와 여러 학생 선택/일괄 배정을 지원합니다. 타격 평가는 날짜를 먼저 만들고 공통 설정 후 학생들을 함께 등록해 순서대로 기록합니다. 선수 사진은 비율을 유지하는 둥근 사각형으로 표시합니다.

선수·팀 여러 항목 삭제/복원과 휴지통 완전삭제를 제공합니다. 완전삭제는 연결된 경기 전체·평가까지 영향을 주므로 삭제 범위 표시와 암호화 백업·확인을 거쳐 실행합니다. [데이터 계약·삭제 범위·변경 파일·조작 단계](docs/BULK_V8.md)를 확인하세요.

## v0.7 학생 공통 명단·삭제·초기화

학생 등록 시 팀을 선택하지 않습니다. **새 경기 → 선공/후공 팀 선택 → 등록 선수 불러오기 → 선발·후보 편성** 순서로 경기마다 배정합니다. 같은 학생을 양 팀에 중복 편성할 수 없으며, 과거 소속 팀과 경기 당시 엔트리는 보존합니다.

선수 & 팀에서 팀 추가·삭제·복원과 선수 등록·삭제·복원을 제공합니다. 타격 평가에는 현재 등록 명단만 표시하며 삭제한 선수의 과거 평가·사진은 보존합니다. 규칙 & 설정에서 기록만 초기화 또는 선수·팀·사진 포함 전체 초기화를 선택합니다. 초기화 전 백업·확인 문구가 필요하고 전체 초기화 백업에는 암호가 필요합니다.

상단 BETA 버튼 또는 설정의 앱 업데이트 확인으로 버전을 확인할 수 있습니다. 입력칸 간격과 Safari 날짜 입력 너비를 보완했습니다. [변경 파일·마이그레이션·조작 단계·남은 확인 사항](docs/MANAGEMENT_V7.md)을 참조하세요.

## v0.6 현장 화면 개선

경기 목록에서 경기를 열고 추가·삭제·복원할 수 있습니다. 선수 & 팀에서는 팀 추가·삭제·복원을 제공합니다. 삭제는 원본을 보존하며 팀을 삭제해도 선수·사진·과거 경기·평가는 남습니다.

아이패드 가로 경기 화면은 공격과 실제 수비 배치를 나란히 표시합니다. 기능평가의 상세 모드는 전체 화면으로 열어 결과·점수·9구역·타구 유형/강도/정확성·회차 기록지를 함께 표시합니다. 긴 기록지는 내부에서 스크롤합니다. [변경 파일·조작 단계·검증·제약](docs/MATCH_UI.md)을 확인하세요.

## 초기 버전의 범위

**서버 인증·접근 권한이 미구현입니다. 실명·학번 등 실제 학생 개인정보를 입력하지 말고 별칭·가상 데이터로 사용하세요. 백업을 저장소에 올리지 마세요.**

## 날짜별 타격 기능평가 v1.0 사용법

1. 기능평가 & 팀워크 → 타격 상세평가에서 선수와 날짜를 선택하고 세션을 생성합니다. 기본 10회이며 1~200회로 직접 설정할 수 있습니다. 같은 날짜에 여러 세션을 만들 수 있습니다.
2. 타격 결과, 9구역, 유형·강도·정확성 및 감독의 1~10점을 선택하고 기록 저장합니다. 순서대로 다음 회차에 입력합니다. 진행 중 세션도 저장한 유효 회차를 유지합니다. 이전 미측정 회차는 보존하며 신규 간편 입력은 결과와 점수가 필요합니다. 파울 관찰은 선택 사항이며 헛스윙은 타구 관찰값을 null로 저장합니다.
3. 기록지의 회차를 터치해 수정자·사유를 입력하여 정정하거나 취소합니다. 세션 정보에서 날짜·목적·상태도 정정할 수 있습니다. 모든 회차를 평가 또는 취소한 후 완료할 수 있습니다.
4. 선수 프로필에서 실전 PA/H와 상세 기능평가를 비교합니다. 기간 필터, 날짜별 평균·누적 추세, 9구역 히트맵과 유형·강도·정확성 비율을 확인합니다.
5. 규칙 & 설정 → 타격 기능평가 설정에서 거리 구역 정의를 새 버전으로 추가하고, 점수 출처 및 참고 성향 분석 기준을 설정합니다.

전체 평균은 날짜별 평균의 재평균이 아니라 유효 회차 점수 합계/회차 수입니다. 15회·126점은 84점입니다. 취소·미평가 제외, 분모 0은 평가 기록 없음, 진행 중 세션은 잠정 평균으로 표시합니다. 기존 수동 점수는 삭제·역산·혼합하지 않습니다. 기본 출처는 상세 기록이며 상세 기록이 없으면 점수 없음입니다. 수동 점수 사용은 설정에서 명시적으로 선택합니다. 최종 선발 점수는 생성하지 않습니다.

거리의 미터 기준과 성향 분석 경계값은 기본 미확정(TODO)입니다. 최소 관찰 수 기본 15개, 경계값이 비어 있는 유형은 판정을 보류합니다. 감사 이력은 로컬 변경 기록이며 인증된 전자서명/위변조 방지 로그가 아닙니다. 신규 평가의 CSV 전용 내보내기 및 실제 iPad Safari 하드웨어 검증은 TODO이며 모든 신규 원본·이력은 JSON 백업에 포함됩니다.

주요 변경 파일: domain/batting.ts, config/batting.ts, assessment/batting.ts·battingSummary.ts, data/schema.ts·schemaV2.ts·migration.ts·repository.ts·seed.ts, components/BattingAssessmentPanel.tsx·BattingAssessmentReport.tsx·BattingAssessmentSettings.tsx, AssessmentView.tsx·Players.tsx·SettingsView.tsx, App.tsx, styles.css 및 평가/마이그레이션/UI 테스트. 상세 계약은 [SPEC](docs/SPEC.md), [MIGRATION](docs/MIGRATION.md)을 참조하세요.

수비 체크리스트는 한 학생의 할당 횟수를 모두 저장한 뒤 다음 학생으로 자동 이동합니다. 남은 횟수를 표시하며, 저장 실패/정정/취소는 학생을 이동시키지 않습니다. 목표 횟수가 없는 이전 날짜는 임의로 이동하지 않고 횟수 설정 또는 직접 학생 선택을 사용합니다.
