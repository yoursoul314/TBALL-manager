# 실행 검증 기록

검증일: 2026-10-20 (Asia/Seoul). 초기 버전 v0.1.

## 환경

- Windows / Node.js 24.19.0 / npm 11.17.0
- React 19.3.1, TypeScript 5.9.3, Vite 7.3.7, Vitest 4.1.12
- npm lockfile 포함, CI는 Node.js 24 / Ubuntu.

## 자동 검증

- TypeScript strict 검사 통과.
- 경기 엔진·평가·통계·저장·UI 테스트 44개 통과.
- 프로덕션 빌드 통과, manifest / 서비스 워커 / 아이콘 및 앱 셸 precache 생성.
- 테스트 과정에서 발견한 Windows 임시 폴더 rename 제한은 프로젝트 내부 임시 폴더를 사용하는 테스트 실행기로 해결.
- 초기 로컬 서버 브라우저 접근은 실행 환경의 loopback 연결 제한으로 시간 초과. 배포 후 HTTPS 페이지에서 별도 확인 예정.

## 검증 범위와 남은 확인

자동 테스트는 확정 규칙 경계, TYPE1 원문 가중치, 정정·재생, 결측과 최적 배치, 정책별 통계, 백업·quota 및 실제 React 파울 입력을 포함합니다.

iPad 실기기 Safari 설치·백그라운드 복귀·장시간 오프라인 저장, 실제 수업 심판 판정, 다중 기기 동기화는 이 테스트로 검증되지 않습니다. 멀티기기 자동 동기화는 미구현입니다.

배포·브라우저 검증 결과는 최종 완료 시 이 파일에 갱신합니다.
