# BETA0.12 아이패드 입력·수비 횟수

## 보존 계획
- schema10→11: defenseDays[].targetAttempts만 추가한다. 이전 날짜는 null(미설정)로 이전하며 가상의 회차나 점수를 만들지 않는다.
- 신규 저장 키는 tb-manager.workspace.v11. v1~v10 원문 키와 마이그레이션 원문을 보존한다. 저장 실패 시 이전 키를 덮어쓰지 않는다. 구버전 키 변경을 감지하면 저장을 차단한다.
- JSON 백업v1~v11 복원을 지원한다. 사진은 기존 IndexedDB 구조/선수ID 참조를 그대로 쓴다.
- 기존 경기 이벤트·승인안·타격평가·수비 원본/정정 이력은 변경하지 않는다. RULE01~08/TYPE1 가중치/주루40:60 및 전체 유효 타격 회차 평균을 유지한다.

## 수비 횟수
- 날짜 생성 시 학생당1~200회 정수를 설정한다. 신규 기본값10회는 UI 제안이며 감독이 바꿀 수 있다. 이전 날짜에는 기본값을 소급 적용하지 않는다.
- 체크리스트의 수비 횟수 설정에서 같은 날짜의 공통 목표를 변경한다. 이미 기록한 학생의 횟수 미만으로 줄일 수 없다. 저장 실패 시 설정 입력을 유지한다.
- 상황1건=기록1회. 최신 상태가 취소이면 제외하고, 정정은 횟수를 늘리지 않는다. 학생별 기록/목표와 완료 상태를 표시한다.
- 완료 후 신규 저장은 차단한다. 추가 관찰은 목표를 늘리고 기록한다. 과거 정정·취소는 계속 가능하다. 학생 이동은 수업 방식에 맞게 수동/저장 후 이동 모두 유지한다.
- 기회 없음도 상황 기록은1회지만 능력 점수 분모에서는 제외한다. 미관찰·취소·미측정 점수를0으로 생성하지 않는다.
- G 땅볼·F 뜬공·C 송구 포구·A 정확도·L 거리/힘·Q 첫 반응·M 범위·J 판단·B 베이스의 행동 설명을 집중 모드에서도 표시한다.

## 키보드와 화면
- [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)의 높이·위치 변경에 맞춰 타격 측정 화면 및 모달의 실제 표시 영역을 조정한다. 키보드가 줄인 영역을 전체 화면 높이와 구분한다.
- 메모/정정 입력 중 저장 버튼을 표시 영역 하단에 유지한다. 버튼을 터치할 때 키보드가 닫히기 전에 버튼이 이동하지 않게 한다.
- 입력칸은16px 글꼴, 필요한 경우 현재 폼만 자동 스크롤한다. 배경 화면의 스크롤이나 기록값을 바꾸지 않는다.
- 작은 키보드 영역에서 모든 관찰을 억지로 축소하지 않는다. 입력과 저장에 접근할 수 있도록 폼 내부 스크롤을 허용한다.
- 새 경기의 승인안→타순→감독 확인→생성 흐름, 가로/세로 전환, 새로고침과 저장 실패를 가상 데이터로 검증한다.

## 검증 한계
WebKit·Chromium iPad 크기 및 VisualViewport 축소/이동을 재현한 자동 테스트는 실제 iPad의 OS 키보드 자체와 같지 않다. 실제 Safari/홈 화면 앱, 분리·플로팅 키보드, 확대 글꼴은 실기기 추가 확인 대상이다. 실제 학생 개인정보를 테스트에 사용하지 않는다.
