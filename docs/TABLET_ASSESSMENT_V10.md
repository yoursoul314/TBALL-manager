# BETA0.10 — 아이패드 평가 데스크·두 선수 판단·수동 배치

## 분석과 보존 계획

v0.9 코드를 확장했다. 타격 기록지 숨김이 전체 화면 상세 모드에만 적용되어 일반 입력 화면에서는 큰 기록지가 남아 있는 것을 확인했다. 수비 집중 모드도 추가 능력을 펼치면 세로로 길어졌다. 기존 날짜 평가/원본/이력/스카우팅과 RULE01~08·TYPE1/TYPE2·9능력 가중치 v2.0·주루40:60·전체 유효 타격 회차 평균은 유지한다.

수동 배치에서 미측정 능력을0점으로 저장하지 않도록 schema10을 먼저 추가했다. Selection.assignments.score는 null을 허용하며 method:manual/automatic, editedFrom(이전 배치안 ID)을 선택 필드로 추가한다. 이전 배치안은 필드/점수를 소급 변경하지 않는다. 1~9명 수동 초안은 저장할 수 있고, 승인 시에는 정확히10개 포지션·서로 다른10명이 필요하다. 경기 엔진의 인원/타순 규칙에는 변화가 없다.

v9 원문은 migrationSource.raw 및 기존 tb-manager.workspace.v9 키에 보존한다. 모든 데이터/참조/경기 재생 검증 후 새 v10 키로 저장하며 용량 오류 시 원문은 그대로 남는다. v1~v10 JSON 복원, v10 내보내기, 구버전 탭 변경 및 revision 충돌 검사, v1~v10 원문 복구를 지원한다. 사진 IndexedDB는 변경하지 않는다. 선수 완전삭제로 이전 배치안이 삭제되면 남은 새 배치안의 끊어진 editedFrom만 정리한다. 기존 삭제 전 백업·확인은 유지한다.

## 화면과 조작

| 기능 | 이전 | 변경 |
|---|---|---|
| 수비9능력 | 추가 펼치기와 세로 이동 | 집중 모드에서9개 상시 표시; 가로3×3·세로2열 |
| 수비 저장 | 화면 아래로 이동 | 같은 화면의56px 저장·다음 학생 버튼 |
| 타격 기록지 | 일반 모드 펼침, 상세만 접기 | 두 모드 기본 접힘; 보기/숨기기1회 |
| 회차 기록 | 여러 상세 줄 | 회차·점수·결과·방향 요약, 최대250px 내부 스크롤 |
| 9구역 분포 | 수치 표/격자 | 홈 기준 경기장9구역, 횟수/비율 전환 |
| 수동 포지션 | 자동 추천만 | 포지션1회→학생1회; 기존 배치 학생이면 맞교환 |

수비 집중 모드의 일반 입력은1024×768/1180×820/820×1180 화면에서 상황·9능력·저장 버튼을 함께 표시한다. 실책/메모/배점 설정·과거 정정 같은 부가 입력을 펼치거나 소프트 키보드가 열린 경우 추가 스크롤이 필요할 수 있다. 미관찰은 중립색이며 성공으로 취급하지 않는다. 모든 주요 수비 선택 버튼은48px 높이, 저장 버튼은56px이다.

타격 기록지를 펼치거나 접어도 초안·회차는 유지한다. 요약에서 회차를 누르면 기존 모든 상세 필드·정정 사유·취소 기능을 사용할 수 있다. 정보 표시만 줄이고 기록을 삭제하지 않는다.

## 시각화와 판단 규칙

9구역은 같은 방향/거리 정의를 재사용한다. 각 구역의 관찰 횟수와 유효 구역 기록 대비 비율을 표시한다. 방향 또는 거리를 모르는 회차는 분모에서 제외하고 개수를 알린다. 색상은 모든 선수에게 같은0~100% 눈금을 사용한다. 표본이 없으면0% 대신 미관찰로 표시한다. 세션별 거리 기준 차이에 대한 안내를 유지한다.

두 선수 판단은 감독이 목적을 고른다: 타격 기능평가, 실전 타격(타율·장타율), 특정 TYPE1 수비 포지션, 타격 기능+수비9항목. 같은 출처·배점이고 항목별 최소 관찰 수를 충족한 지표만 비교한다. 기본 최소 수는 기존 설정(초기15)을 사용하며 화면에서 변경 가능하다. 비교 학생별 점수/비율과 표본 수를 함께 제시한다.

필요 지표에서 뒤지는 항목 없이 하나 이상 앞서면 해당 선수를 우선 검토하도록 권고한다. 지표별 우위가 서로 다르면 장점과 상충을 설명하고 목적을 좁혀 선택하도록 한다. 동점·미측정·표본 부족·다른 배점은 우위를 임의 확정하지 않는다. 비교 수치 차이는 인과 또는 통계적 유의성 판정이 아니다. 목적별 참고 판단이며 미확정 최종 가중치/공식 엔트리를 생성하지 않는다.

## 수동 배치와 승인

선발 시뮬레이션에서 수동 배치 버튼 또는 필드의 포지션을 누른다. 학년·반·검색으로 등록된 출전 가능 학생을 고른다. 중복 학생을 선택하면 기존 자리와 교환하고, 빈 자리로 옮기면 기존 자리를 비운다. 미측정 적합도는null/—이며 배치는 가능하다. 이미 출전 불가/삭제된 학생이 있는 과거 배치는 조회할 수 있지만 신규 저장·승인 때는 정리해야 한다.

저장은 새 초안을 추가한다. 저장 실패 시 편집 내용을 유지하고, 미저장 상태에서 메뉴 전환/업데이트는 기존 보호 기능으로 차단한다. 승인된 안을 편집하면 이전 승인안은 보존하고 새 초안은 재승인해야 한다. 최신 데이터 revision이 아니면 다시 저장/시뮬레이션해야 승인할 수 있다. 시범 수비 배치 승인이며 실제 경기 엔트리나 최종 종합 선발을 자동 확정하지 않는다.
