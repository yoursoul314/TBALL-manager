# BETA0.8 학급 일괄 편성·날짜별 평가·사진·완전삭제

## 사용자 흐름

- 경기: 새 경기 → 등록 선수 불러오기 → 학년/반/검색 필터 → 학생 체크 또는 표시 결과 전체 선택 → 선발/교체 후보/미출전/결석/출전 불가 지정 → 선택 학생 팀에 배정. 필터를 바꾸어도 선택은 유지하며 선택 인원을 표시한다. 반대편 팀 중복, 출전 불가의 선발/후보, 선발10명 초과를 전체 적용 전에 검증한다. 타순은 선택 순서이며 이후 직접 조정할 수 있다.
- 타격: 날짜별 함께 평가 → 날짜/공통 횟수/평가자/목적/메모 생성 → 학년/반별 학생 여러 명 선택 → 선택 학생 평가 시작 → 상세 화면에서 기록·다음 학생 이동. 날짜만 먼저 저장해도 새로고침 후 유지된다. 같은 날짜에 진행/완료 세션이 있는 학생은 기존 세션을 이어가며 취소 세션만 있으면 새 차수를 만든다. 개인별 이전 기록 탭에서 기존 세션 조회·추가·정정을 계속 제공한다.
- 학생별 점수와 회차는 기존 원본 배열을 사용한다. 날짜별 학생 목록은 해당 날짜의 실제 세션에서 계산하며 점수 미입력 학생을0점으로 만들지 않는다. 학생별 평균은 전체 유효 회차 기준이고 다른 학생 또는 경기 통계와 합치지 않는다. 저장 전 다음 학생 이동은 막고 저장 실패 시 입력·학생 선택을 유지한다.
- 사진: 원형/작은 틀의 cover 표시 대신 둥근 사각형과 contain을 사용한다. 프로필은96×120px, 명단은64×76px로 원본 비율과 전체 사진을 보존한다. 배경 여백은 허용하며 얼굴 인식·자동 사진 편집은 하지 않는다.
- 선수 & 팀: 체크박스로 여러 항목 선택 → 선택 삭제/복원. 휴지통의 복원 버튼 옆에 삭제(완전)과 선택 항목 완전삭제를 제공한다.

## 완전삭제 범위

사용자는 연결된 경기·평가도 함께 삭제하는 방식을 명시적으로 선택했다. 부분적인 경기 이벤트 제거는 재생을 깨뜨리므로 연결 경기는 다른 학생의 해당 경기 기록까지 포함해 경기 전체로 제거한다. 실행 전 경기·이벤트·기능평가·타격 세션/회차·팀워크·추천·사진 수를 표시한다.

- 선수 완전삭제: 선택 선수·사진, 그 선수가 엔트리/이벤트에 있는 경기 전체, 해당 선수의 기능평가·타격 세션/회차/감사·팀워크·관련 추천을 제거한다. 다른 학생의 독립 평가는 유지한다.
- 팀 완전삭제: 팀과 해당 팀 경기 전체·경기 연결 팀워크·관련 추천을 제거한다. 등록 선수와 사진·독립 평가는 유지하고 기존 소속 teamId만 null로 바꾸어 공통 명단에 남긴다.
- 삭제된 항목만 완전삭제할 수 있고 연결 경기의 플레이가 진행 중이면 차단한다. 여러 항목 적용은 먼저 전체 검증한 뒤 저장하며 일부만 삭제하지 않는다.
- 사진 포함 전체 암호화 백업(암호10자 이상) → 백업/삭제 범위 확인 → 완전삭제 문구 → 실행을 요구한다. 백업 후 리비전이 달라지면 다시 백업한다. 삭제 정보가 다시 로드되지 않도록 이전 스키마 키와 원문 출처를 제거한다. 외부 백업 파일은 사용자가 별도로 관리한다.
- 사진/기록 저장 중 일반 오류는 이전 사진과 키로 복구한다. localStorage와 IndexedDB를 아우르는 프로세스 강제 종료 원자성은 제공하지 않는다. 같은 기기에서 여러 탭 동시 기록은 피한다.

## 데이터 이전

스키마8, 새 키 tb-manager.workspace.v8. battingDays 배열에 날짜·공통 설정·생성 시각을 추가한다. 기존 v1~v7의 키와 원문을 일반 이전 과정에서 유지한다. 새 배열은 빈 배열이며 기존 세션 날짜는 조회 시 함께 표시한다. 기존 학생별 세션·회차·감사 이력에 새 날짜나 평가값을 역산해서 넣지 않는다.

이전 v7 기준본 변경을 탐지하고 충돌 시 저장을 막는다. JSON 읽기1~8, 쓰기8. 날짜만 있는 작업공간도 백업·재열기 가능하다. 평가/전체 기록 초기화는 battingDays도 비우고 경기만 초기화는 평가 날짜를 유지한다. 명시적인 전체 초기화 또는 완전삭제만 이전 저장 키를 정리한다.
