# v0.11 승인 배치안 불러오기와 타격 측정 전용 화면

## 데이터 보존 계획 및 구현

- schema v10 유지. 새로운 영구 저장 필드나 소급 변환은 필요하지 않다.
- 승인 Selection 원본은 읽기만 한다. 새 경기의 기존 lineups / rosters / entry.players / entry.defense에 복사한다.
- 기존 JSON 백업(v1~v10), 마이그레이션 원문, 사진 IndexedDB, 기존 경기·평가·정정 이력은 유지한다.
- 측정 화면의 탭·페이지는 임시 UI 상태다. 탭 전환은 AttemptEditor를 해제하지 않아 미저장 초안을 유지한다. 저장 실패 시에도 같은 초안을 유지한다.

## 승인 배치안을 새 경기로

1. 선발 시뮬레이션에서 10개 포지션을 배치하고 감독 승인한다.
2. 새 경기에서 선공/후공 팀을 선택하고 각 팀의 감독 승인 배치안을 선택한다.
3. 승인 배치안 적용: 선발 10명·수비 10개 위치를 복사한다. 교체 후보는 유지하고 기존 선발 중 승인안에 없는 학생은 미출전으로 바꾼다.
4. 타순 위·아래 버튼으로 직접 조정한다. 기존 선발 타순은 가능한 범위에서 유지하고, 새로 불러온 학생은 TYPE1 포지션 순서의 임시 타순이다. 타순 추천 알고리즘이 아니다.
5. 양 팀 엔트리를 확인한 감독 이름과 확인 체크 후 경기를 생성한다.

초안·다른 팀·중복·10명 미완성·삭제·출전 불가·당일 결석·상대 팀 중복을 전체 적용 전에 검사한다. 실패 시 기존 편성은 그대로다. 승인 이후 평가가 변해도 배치를 자동 재계산하지 않는다. 최종 종합 선발 가중치는 여전히 TODO다.

## 타격평가 화면

- 날짜·설정 → 학생 선택 → 측정 시작의 단계별 화면으로 분리한다.
- 측정 전용 화면 상단에 선수·날짜·회차·오늘 평균·누적 점수·학생 이동을 표시한다.
- 측정 / 기록지 조회 / 세션·설정 / 성장 분석을 클릭해서 이동한다.
- 상세 측정은 결과·1~10점, 9구역 맵, 유형·강도·정확성을 한 화면에 배치한다. 간편 모드도 같은 전용 화면을 쓴다.
- 메모·정정은 별도 입력 페이지에 둔다. 기존 회차 수정에는 수정자와 사유가 필수다.
- 기록지는 측정 화면을 차지하지 않으며 10회씩 페이지 이동한다. 회차를 누르면 측정 화면으로 돌아가 수정한다. 감사 이력과 세션 완료·취소·수정 기능은 유지한다.
- 미저장 상태에서는 학생 이동·종료를 막으며, 조회 탭 전환은 초안을 유지한다. 이전 화면의 값을 다음 회차에 복사하지 않는다.
- 유효 회차 합계/횟수 ×10 계산은 변경하지 않았다. 방향·강도·정타에서 점수를 자동 생성하지 않는다.

## 조작 변화

- 경기: 승인안을 보면서 10명을 선택하고 10개 위치를 다시 지정하던 과정을 팀당 승인안 선택 + 적용으로 줄인다. 최신 승인안이면 적용 1회, 다른 승인안이면 선택 1회 추가. 타순 조정과 최종 감독 확인은 유지한다.
- 평가: 간편 입력은 결과 → 점수 → 저장 3터치. 상세 전체 관찰은 결과·9구역·유형·강도·정확성·점수·저장 7터치. 기록지나 분석은 별도 탭 1터치로 조회하고 측정 탭 1터치로 복귀한다.
- 회차 저장과 다음 회차 자동 이동, 마지막 기록 취소, 이전·다음 학생은 유지한다.
