# BETA 0.14.1 — 평가목적 선택과 삭제/복원 재검증

날짜 생성 시 공통 평가목적의 타격 평가/수비 평가를 터치해 선택한다. 별도 목적은 직접 입력할 수 있다. 기존 기록의 목적은 변경하지 않고 기존 purpose 문자열을 사용하므로 추가 마이그레이션이 없다. 평가자 등록/터치 선택, 원본을 보존하는 삭제/복원 계약은 0.14.0과 동일하다.

변경 파일: AssessmentPurposePicker.tsx, BattingDayView.tsx, DefenseDayView.tsx, styles.css, 버전 파일 및 QA 기대 버전, scripts/assessment-average-qa.cjs. RULE01~08 및 TYPE1 가중치, 평가 환산/평균 함수는 변경하지 않는다.

## 검증 시나리오

독립 WebKit iPad 터치 환경에서 가상 학생만 사용한다. 날짜1 타격5/1점, 날짜2 타격2점을 UI로 저장한다. 누적은8/3 원점수,100점 환산61.1이다. 첫5점 회차를 삭제하면41.7, 복원하면61.1이며 날짜별 평균도 확인한다. 날짜1 전체 삭제는50.0, 전체 삭제는 평가 기록 없음이어야 한다.

수비 G 성공/부분 수행/실패3건은50.0점이다. 성공1건 삭제는25.0, 복원은50.0이다. 날짜1을 삭제해 실패1건만 남으면0.0점, 전체 삭제는 미측정이어야 한다. F 등 관찰하지 않은 항목은 계속 미측정이다.

각 단계의 선수 프로필 수치를 확인하고, 세로 모드에서 날짜를 모두 복원한 뒤 재로딩하여 평균·기록·원본 이력을 확인한다. 테스트는 실기 iPad 자체를 제어하지 않으며 실제 학생 자료를 읽거나 변경하지 않는다.
